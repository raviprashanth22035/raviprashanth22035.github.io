# Portfolio

Static portfolio site for GitHub Pages. No build step.

## Publish

1. Create a public repo named `raviprashanth22035.github.io`.
2. Push the contents of this folder to `main`.
3. In the repo, go to Settings, Pages, and set the source to `main` and `/ (root)`.
4. The site goes live at https://raviprashanth22035.github.io

## Structure

- `index.html`, `experience.html`, `projects.html`, `contact.html`
- `assets/style.css` for the design tokens and layout
- `assets/site.js` for the light and dark toggle
